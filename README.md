Simple Interest Calculator

Project Description

This project is a simple interest calculator. It calculates the simple interest based on the principal amount, interest rate, and time period.

Formula

Simple Interest = (Principal × Rate × Time) / 100

Inputs

- Principal: The initial amount of money.
- Rate: The annual interest rate.
- Time: The period in years.

Example

If the principal is 1000, the rate is 5%, and the time is 2 years:

Simple Interest = (1000 × 5 × 2) / 100

Result = 100

Purpose

The purpose of this project is to demonstrate how simple interest is calculated using a basic mathematical formula.
